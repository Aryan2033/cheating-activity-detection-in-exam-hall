Exam Hall Cheating Detection System

This project is an AI-based video surveillance system designed to assist exam invigilators. It uses computer vision to analyze exam hall video, identify suspicious cheating activity, and generate evidence that can be reviewed by a human authority.

Video-Based Cheating Detection

The system processes uploaded or streamed exam hall video frame by frame. Each frame is passed to a trained YOLO object detection model, which classifies suspicious activity as cheating or not cheating and returns a bounding box with a confidence score.

Data Collection: Exam hall video frames are collected and annotated for cheating-related behavior.

Preprocessing: Video frames are read using OpenCV and prepared for model inference.

Model Selection: YOLO is used because it is fast, suitable for video analysis, and provides both class prediction and object localization.

Detection Output: The system draws bounding boxes, saves detected screenshots, records timestamp and confidence, and can send an email alert.

The purpose of the system is to support invigilators by flagging suspicious moments for review, not to make automatic disciplinary decisions.
